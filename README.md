# 🛰️ Автоматический КВ/УКВ-радиомаяк на RP2040 (RP2040_beacon)


**RP2040_beacon** — это многофункциональный автоматический КВ/УКВ-радиомаяк, построенный на базе микроконтроллера RP2040 (с полной поддержкой миниатюрных плат **RP2040-Zero**). Проект ориентирован на радиолюбительские эксперименты, исследование прохождения радиоволн и оперативную передачу телеметрии в эфир.

> **Текущая версия:** `2.10` от `2026-09-26`

---

## ⚡ Основные возможности

* **Разнообразие цифровых режимов:** Поддержка классического **CW** (телеграф), **RTTY** (радиотелетайп) и помехоустойчивого многочастотного **IFKP**.
* **Гибкое формирование ВЧ-сигнала:** 
  * Штатный режим: работа с внешним высокоточным синтезатором частоты **Si5351**.
  * Аварийный/резервный режим: собственная **программная DDS-генерация меандра** с автотюнингом PLL и дизерингом MASH-2 на автоматах **PIO** (выполняется на изолированном ядре `Core 1`).
* **Умное сканирование шины I2C:** Автоматическое определение подключенной периферии (дисплей, датчики, часы реального времени) прямо при старте.
* **Автономная работа:** Встроенное расписание трансляций с привязкой к реальному времени.
* **Полноценная телеметрия:** Автоматическое формирование пакетов передачи, включающих системные параметры и климатические данные (температура, влажность, давление).
* **Удобное управление:** Текстовый конфигурационный файл на встроенном USB-диске платы и развитый консольный интерфейс через Serial-порт.

## 🎛️ Аппаратная часть и интерфейсы (Hardware)

Маяк спроектирован под аппаратную архитектуру чипа RP2040. Вся внешняя периферия подключается по общей шине **I2C**.

### Адреса I2C устройств

| Устройство / Модуль | Адрес на шине I2C | Назначение |
| :--- | :--- | :--- |
| **Si5351** | `0x60` | Основной внешний ВЧ-синтезатор частоты |
| **DS3231 / DS1307** | `0x68` | Модуль часов реального времени (RTC) |
| **LCD Дисплей** | `0x27` | Экран вывода системного статуса и параметров |
| **BME280 / BMP280** | Автосканирование | Климатический датчик (давление, температура, влажность) |
| **AT24Cxx** | Автосканирование | Внешняя энергонезависимая память EEPROM |

### Выход ВЧ-сигнала (VFO)
* **`GPIO 14`** — основной выходной пин для подключения к буферному усилителю или антенной цепи при работе встроенного PIO/DDS генератора (`VFO_OUTPUT_PIN = 14`).
* *Аппаратное ограничение программного DDS:* Обеспечивает чистую и стабильную сетку частот на КВ-диапазонах до **14–15 МГц**. На диапазоне 10 метров (28 МГц) генерация возможна, но упирается в пределы прямого делителя PIO. Для калибровки кварца используется параметр `VFO_CALIBRATED_XOSC_HZ`.

## 📦 Как скачать и установить готовую прошивку

Вам не обязательно устанавливать среды разработки для запуска маяка. Вы можете использовать полностью готовые бинарные файлы прошивки:

### 1. Официальные релизы (Рекомендуется)
Перейдите на страницу **[GitHub Releases](https://github.com/ru0aog/RP2040_beacon/releases)**. При создании каждого нового тега версии (`v*`) робот автоматически компилирует код и прикрепляет чистый файл **`.uf2`** в раздел *Assets*.

### 2. Свежие сборки «на лету»
Если вы хотите протестировать самые последние изменения, перейдите на вкладку **[GitHub Actions](https://github.com/ru0aog/RP2040_beacon/actions)**, выберите самый верхний успешный запуск сборки и скачайте архив артефакта **`arduino-rp2040-uf2`** из нижней части страницы.

### Инструкция по прошивке:
1. Зажмите аппаратную кнопку **BOOTSEL** на вашей плате (RP2040 / RP2040-Zero).
2. Не отпуская кнопку, подключите плату по USB-кабелю к компьютеру, после чего отпустите её.
3. В системе появится новый съемный накопитель **`RPI-RP2`**.
4. Просто **скопируйте (перетащите)** ваш скачанный `.uf2` файл на этот диск. Плата автоматически перезагрузится, применит прошивку и сразу начнет работу по заданному алгоритму.

## 💻 Сборка из исходного кода

Для самостоятельного изменения логики и локальной компиляции проекта вам понадобятся:

1. Среда разработки **Arduino IDE**.
2. Установленное стороннее ядро плат **Raspberry Pi Pico/RP2040** от *Earle F. Philhower* (добавьте ссылку на индекс плат в настройки: `https://github.com`).
3. Библиотека **Adafruit TinyUSB Library**, установленная через стандартный менеджер библиотек.

### Конфигурация платы в Arduino IDE (FQBN):
При прошивке из IDE или сборке через CLI используйте следующие настройки:
* **Плата:** *Raspberry Pi Pico* (или аналогичная RP2040)
* **USB Stack:** *Adafruit TinyUSB*
* **Flash Size:** *2MB (Sketch: 1MB, FS: 1MB)* 
* *Строка FQBN для компилятора:* `rp2040:rp2040:rpipico:usbstack=tinyusb,flash=2097152_1048576`

## 🖥️ Интерфейс консольных команд (CLI)

Подключившись к плате через любой монитор Serial-порта (скорость 115200), вы можете гибко управлять маяком с помощью текстовых команд:

* **`?`** или **`help`** — вывод справочной информации и списка всех доступных команд.
* **`tele`** — мгновенный вывод текущей телеметрии (напряжение, аптайм, данные датчика BME/BMP280) в консоль.
* **`time`** — просмотр или ручная корректировка текущего времени.
* **`date`** — просмотр или корректировка текущей даты.
* **`text`** — изменение или просмотр текстовой строки, передаваемой маяком в эфир.
* **`setparam M=V`** — установка значения `V` для внутреннего параметра конфигурации `M`.
* **`start cw` | `rtty` | `ifkp`** — принудительный ручной запуск трансляции маяка в выбранном режиме модуляции.
* **`stop`** — мгновенная остановка текущей передачи и переход в режим ожидания.
* **`restart`** — программная перезагрузка маяка.
* **`reset`** — сброс всех измененных параметров к заводским настройкам по умолчанию.
